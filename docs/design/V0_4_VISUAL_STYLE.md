## 2. 继承的视觉特征

1. 黑灰分层背景，主界面为一块大工作面，以少量分隔线区分内容。
2. 左侧固定配置列表，顶部主导航，中央展示核心内容，下方横向分组调整参数。
3. 蓝色用于选中项、焦点和开始操作；普通控件采用深灰，不让所有按钮都争夺注意。
4. 按用户要求加粗导航、标题、参数标签、按钮和数值；通过字号、位置与颜色维持层次，不再依赖偏细字重。
5. 细线图标、克制圆角、紧凑控件；用空间和对齐形成层次，不堆叠阴影或发光效果。

只继承参考的风格与信息布局。键盘设备、灯光面板、账号、皮肤商城与云社区等与控制实验无关的内容不加入本项目。

## 3. 布局

### 左侧：配置与预设

品牌名称、新建配置、导入配置、打开实验、实验列表、我的配置/示例预设、当前配置摘要、帮助。

列表选中项使用蓝色文字、细边框和左侧短标记。未运行的配置标为“草稿”，不能凭空显示已完成状态。

### 顶部：功能导航

主导航为实验对比、预算整定、历史实验；报告导出是上下文操作。主导航和曲线子标签分层，避免把“真实输出”“CSV”“设置”等混在同一导航中。

### 中央：响应与指标

上方响应图优先展示，支持输出/误差/实际输入切换。参考用灰色虚线，控制器曲线各用固定颜色；图例、单位、事件时刻清晰可见。

最新稿将响应区扩大至主工作区约三分之二，实际绘图区从1210×184改为1250×360，面积约为原来的两倍。下方三栏使用紧凑数值框，保留关键配置；正式实现的面板应可缩放或滚动，不固定采用设计稿像素。

图下方用一条简洁指标带显示RMSE、IAE、输入变化量、饱和比例与恢复状态。详细逐控制器表在结果详情或展开面板中，不把总览带误作某种算法的综合分。

### 下方：三栏参数

- 对象与控制器：一阶/二阶对象、物理参数、算法选择及参数编辑入口。
- 参考与扰动：波形、幅值、事件时刻与启用状态；其他波形通过完整选择面板提供，稿中三个快捷按钮不代表只有三种波形。
- 实验条件：采样、时长、限幅、测量延迟、噪声；随机种子、评价窗口和恢复判据保留在高级设置。

底部状态栏常驻，统一显示准备/运行/取消/完成/异常。右下角只有一个主要操作；运行时“开始对比”切换为取消或停止请求，行为遵循运行服务。

## 4. 颜色与文字

| 角色 | 值 | 用途 |
|---|---|---|
| 窗口背景 | `#0B0C0E` | 外框与侧栏背景 |
| 工作面 | `#121315` | 大工作区 |
| 控件底色 | `#1C1E22` | 按钮、输入框与次级操作 |
| 分隔/边框 | `#2B2E34` | 轻边界，不当作主要内容 |
| 主文字 | `#F2F3F5` | 标题、标签、输入值 |
| 次文字 | `#B3BAC7` | 单位、提示、说明，提高加粗后的可读性 |
| 主强调 | `#2878FF` | 开始操作、选中、焦点 |
| 辅助曲线 | `#49CFBC` | 第二控制器和状态辅助 |

曲线另预留橙色、紫色；同一控制器跨标签页保持颜色。成功、失败、未完成、不可用同时用文字区分，不能仅靠红绿或透明度表达。

中文优先微软雅黑；实际Qt实现采用系统字体回退。设计目标：常规文字14～16逻辑像素，导航18～20，栏目标题20～23，品牌30～32；具体在Windows缩放下验证，不机械照搬图片像素。

设计稿使用粗体；实现时主要控件标签和数值使用600～700字重，标题700。图轴刻度和图例同步加粗，曲线适当增加线宽，不能只放大空白背景。

## 5. 控件状态

- 常规按钮：深灰底；悬停提高背景亮度，按下反馈明确。
- 选中：暗蓝底、蓝色文字/边框；与键盘焦点样式分开。
- 主按钮：纯蓝底、白字；不在同一视图放多个同等级主按钮。
- 禁用：降低对比，并且实际不可触发；尚无结果时导出报告禁用。
- 错误：字段附近解释原因，不仅在窗口底部输出异常日志。
- 加载：显示真实进度或明确不确定状态，不伪造百分比。
- 输入：数值可键盘输入、选择、复制；必要时微调，不为视觉统一把所有物理量换成滑块。
- 开关：开/关有清晰位置与文字含义，颜色只是辅助。

设计稿1800×1120用于讨论，不是固定窗口尺寸。实现时参数区允许滚动，验证1280×800及Windows 125%/150%/200%缩放，避免小屏裁掉运行按钮。原生窗口功能、拖动、缩放、最小化/最大化/关闭和键盘操作必须保留。

## 6. 图表

界面内嵌图使用深色背景和低对比网格；线条比网格明显，轴标签不使用难辨的近黑灰。

显示抽样不能影响原始指标或保存轨迹。未运行不显示伪造分数；若展示占位响应，始终明确标注，正式软件空状态优先显示说明与信号预览。

论文/分享导出的图可提供白底主题，与桌面深色外观独立；不能因软件为深色就强制所有报告图片也是黑底。

主题参数集中维护；Qt界面、Matplotlib图、导出主题分别适配，共享颜色角色，避免每页各写一套颜色。
