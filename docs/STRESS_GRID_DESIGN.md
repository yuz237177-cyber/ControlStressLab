# 扰动强度与测量延迟扫描：预先约定

本轮沿用实验设计原则：完整交叉两个因子，固定对象与控制器增益，保留同延迟下的零负载对照。
参数不确定性上一轮成果已独立归档，本轮不叠加J/b变化或随机测量噪声。

## 固定范围

- 对象为标称约化电机；两种控制器均Kp=0.25、Ki=0.8、Kd=0，仅条件积分抗饱和开关不同。
- 负载阶跃幅值0、0.05、…、0.60 N m，共13级；测量纯延迟0、0.05、…、0.50 s，共11级。
- 每个点运行两控制器，共13×11×2=286次。每个延迟/控制器的零负载点同时作为配对对照，不重复计数。
- 周期0.01 s、持续20 s，0.5 s参考升至60 rad/s，8 s加入恒定负载。所有延迟必须是采样周期整数倍。
- 对象与控制器每次重新创建、复位；每次完整运行是记录单位。确定性固定遍历，无概率权重、无重复样本置信区间。
- 主评价区间为[8,20) s，恢复从8 s起算；采用±1.2 rad/s、最终持续至少0.5 s且直到观察结束不出带的原有判据。
- 事件前[7.5,8] s的真实误差全部在带内才标记pre_event_settled=true。较大延迟可能在负载之前已产生振荡，不能默认起步结束。

## 指标与状态

同时保存原始事件后IAE/RMSE、恢复时间、输入总变差、饱和比例；保存有/无负载输出差的绝对值积分。
配对轨迹必须在8 s前逐点相同。零负载的增量指标为0；失败/非有限结果为null，不能以0替代。

由模型独立计算维持60 rad/s所需电压u=(b+Kt·Ke/R)·60·R/Kt + load·R/Kt。
标称模型、±12 V下，精确维持60 rad/s的正向负载上限为0.54 N m。
这只是稳态参考的可达性条件，不是动态稳定裕度；0.54也不是任何误差带判据的精确临界值。

分类顺序：运行/指标失败；精确稳态参考不可达；可达但观察窗内未恢复；观察窗内恢复。
同时保留独立的recovery_status及pre_event_settled标记，避免互相遮蔽。
每个延迟下给出各负载采样点状态，不假定状态随负载或延迟单调，不从网格插值“精确临界延迟”。
不会把未恢复称为数学意义不稳定，也不会把网格点比例解释为真实失效概率。
