# 参数不确定性扫描：预先约定

本阶段为确定性、探索性参数网格，不进行控制器重新调参，也不假定参数服从任何概率分布。
问题：标称控制器在电机惯量J、机械粘性摩擦b偏离标称值时，性能如何变化？

## 设计

- 对象仍为约化直流电机，J0=0.01 kg m²、b0=0.001 N m s，均为合成教学假设。
- J/J0和b/b0分别取0.50、0.75、1.00、1.25、1.50、1.75、2.00，完整交叉为49个点。
- 每一点运行普通PID与条件积分抗饱和PID，增益固定为Kp=0.25、Ki=0.8、Kd=0。
- 在nominal与load_step两种无噪声、无延迟场景分别运行：共49×2×2=196次。
- 单次完整运行是记录单位。每次重新创建并复位对象/控制器，初态、参考、负载、限幅及窗口保持一致。
- dt=0.01 s、持续12 s。nominal评价事件为0.5 s，load_step为4 s；后者排除4秒以前的误差积分，但不自动排除事件后的残余起步瞬态。
- 确定性仿真没有实验日漂移，采用固定遍历顺序便于核对；不需要用随机顺序模拟独立重复。
- 两个因子较少且关心联合变化，使用完整二维网格。穿过(1,1)的切片给出单因子结果；组合点用于观察交互影响。
- 扫描范围是人为选定的探索域，不是硬件公差、置信区间或真实参数分布。

## 输出与解释

主要响应为事件后IAE；同时记录事件后RMSE、恢复时间与恢复状态、全评价窗口输入总变差和饱和比例。
绝对IAE与相对于同一控制器、同一场景标称点的比值一起保存。标称值为0或运行失败时比值为null。
两控制器的事件后IAE差值定义为“抗饱和−普通”，正值表示抗饱和在该点的此项指标更大。
不同指标分别解释，不合成总分；不同场景不混合排名。

恢复仍采用现有±1.2 rad/s误差带、最终连续至少0.5 s的有限窗口判据。
未恢复、输出越界、接口/数值失败与指标失败分别计数，图中明确区分，不用0填补缺失值。
所有配置、逐次指标与轨迹指纹均保存；默认保留标称点和每个场景/控制器事件后IAE最大的有效网格点的CSV。
该“最大值”只覆盖已运行的离散网格。没有概率权重，不把点数比例解释成现实失效概率。
参数网格通过不证明连续参数区域内的鲁棒稳定性，也不证明硬件有效性。

机械摩擦b只占总阻尼b+Kt·Ke/R的一部分。相同倍数的J、b变化可能造成很不相同的动态影响，
因此同时记录总阻尼、等效时间常数与静态电压增益，帮助解释结果。

## 首轮之后的解释性补充

首轮196次结果保存在outputs/uncertainty-first-grid，未覆盖。观察到大惯量下4秒时起步瞬态可能仍未结束，
因此在后续版本补充有/无负载配对输出的增量指标，保持原有IAE定义、扫描范围、控制器和场景全部不变。
新增量为同J、b和控制器下，积分∫[4,12)|y_load−y_no_load|dt，采用相同左端保持约定。
这是配对轨迹差的绝对值积分，不是两项IAE相减；适用于此次给定初始过程下的负载干预效应，不能直接当作已稳态时的抗扰指标。
标称与负载场景按每一点相邻运行，避免保留整个网格的轨迹缓存；初始过程至4秒的输出应逐点相同。
