## 交付目标

完成一条约6分钟、面向自动化专业学生的中文演示视频。观众能看懂问题、配置一次实验、解释控制器差异，并找到源码和可复现报告。

最终交付包括成片MP4、独立SRT字幕、真人口播稿、封面、标题/简介、章节时间轴及录制所用配置和实验数据。原始录屏、配音与剪辑素材保存在本机。账号上传另按用户当时的指示执行；当前先准备内容与产品演示流程。

## v0.5优先实现

| 工作 | 对演示的作用 | 验收方式 |
|---|---|---|
| 可重现的演示预设 | 减少现场临时输入，让观众能复现同一条件 | 发布配置、种子、评价窗口及结果来源 |
| 跨实验结果对照 | 清楚展示同一对象/控制器在不同条件下的变化 | 校验对象、控制器参数与共同条件；明确列出改变的因素 |
| 演示视图 | 图、单位、图例和当前实验条件在1080p画面中可读 | 实际录制检查，保留输出/误差/实际输入切换 |
| 事件说明 | 观众能识别参考变化与扰动施加时刻 | 标记来自真实配置，不手工伪造数据事件 |
| 连贯操作流程 | 从选择配置到报告导出可以一遍完成 | 在真实软件中完整走通，并保留录屏及原始结果 |
| 视频素材与使用指引 | 视频发布后，观众有明确的复现入口 | 字幕、讲稿、封面、简介及GitHub链接齐全 |

预算整定沿用既有协议，解读训练选择与留出测试；本轮功能优先服务完整演示。便携EXE仍需独立完成部署和干净环境验收；视频启动说明使用实际可提供的分发方式。

## 演示案例

### 案例一：一阶对象的抗扰与取舍

对象使用一阶惯性模型，主画面比较抗饱和PID与LADRC，参数固定，先展示输出和参考，再切到实际输入。必要时在图例中隐藏其他曲线，保证视频可读。

录制前核对参考变化、扰动时刻和指标窗口。展示两条曲线的差异，同时说明误差较小可能伴随输入动作变化；实际结论根据本轮运行结果确定。

### 案例二：噪声和延迟分步加入

| 配置 | 噪声标准差 | 测量延迟 | 用途 |
|---|---:|---:|---|
| A | 0 | 0 s | 干净基线 |
| B | 0.02 | 0 s | A→B只增加噪声 |
| C | 0.02 | 0.07 s | B→C只增加延迟 |

三组保持模型、参考、扰动、控制器参数、限幅、采样、种子和评价窗口相同。新对照视图应显示差异清单，防止把同时改了多项配置的结果解释成单因素影响。

展示输出和实际输入两个角度。结论描述这组参数下的观察结果，不能推广为某算法必然更优。

### 案例三：二阶振荡对象

切换到质量—弹簧—阻尼模型，展示正弦跟踪。明确位移单位m，控制和扰动力单位N；让观众理解项目覆盖动力学类型。说明持续变化参考的常数恢复时间不适用。

### 案例四：训练改善是否能带到测试

沿用默认完整协议：2对象×4方案，每组32候选、3训练场景，768次训练+384次冻结测试，共1152次。耗时计算段可剪短或加速，画面明确标注。

使用本次新跑且已核验的完整报告进行解释。录制前从保存指标中选取一个清楚的取舍案例，讲稿再填入实际数值。快速160次协议与完整1152次协议分别标明，不能混用运行画面和结果。

### 结尾：完整报告与GitHub

从软件导出报告，展示HTML、原始CSV、实际配置、图表和校验清单；给出该视频对应的版本标签、演示配置与数据入口。

## 6分钟分镜

| 时间 | 画面 | 观众获得的信息 |
|---|---|---|
| 00:00–00:30 | 完整界面、两条响应、项目名称 | 这是什么工具，解决什么问题 |
| 00:30–01:30 | 一阶配置→运行→输出/输入 | 公平对照与误差/动作的取舍 |
| 01:30–02:35 | A/B/C配置与对照 | 噪声、延迟如何改变表现 |
| 02:35–03:20 | 二阶对象正弦跟踪 | 适用范围、物理单位与恢复语义 |
| 03:20–04:40 | 预算设置、训练/冻结、结果 | 训练改善不保证测试改善 |
| 04:40–06:00 | 报告、数据、GitHub与结尾 | 结果来源、复现方法和项目边界 |

时间是剪辑目标，按真人口播速度和录屏节奏微调。录制前完成实际结果审查，再锁定讲稿。

## 制作顺序

1. 完成演示预设、跨实验对照与界面可读性；同步保留原数值和证据链检查。
2. 新建数据目录执行全部演示案例，核对配置差异、输入配对、指标和产物完整性。
3. 真实软件录制画面，保留原始片段；先剪出无配音画面版，确认操作能被观众看清。
4. 按实际画面和数据修订口播稿，标明停顿、数值和重点。
5. 用户按定稿录制真人配音，按章节提供原始音频；随后完成声音、画面和字幕对齐。
6. 输出完整成片、字幕、封面、简介及复现材料，通看检查后准备发布。

目标画面为1920×1080横屏、30fps；成片使用常见MP4格式。这是制作目标，上传平台的实时要求在实际发布时核对。

## 素材组织

大体积素材保存在被Git忽略的 `outputs/video-v0.5/`：

```text
configs/       实际录制配置
experiments/   完整数据、图表和报告
recordings/    原始软件录屏
voice/         用户真人原音
edit/          剪辑工程及中间文件
exports/       成片、字幕和封面
manifest.json  版本、配置、素材和数据来源
```

公开仓库保留讲稿、简要制作说明、演示配置和适量截图；完整视频和大体积素材另行提供。

## 成片验收

- 真实软件操作与真实实验数据对应；静态示意图与已保存数据回放明确标注。
- 不把离线批次计算包装成真实硬件实时控制；口播明确是合成仿真。
- 参数、单位、图例和字幕在1080p正常观看尺寸下清楚；画面重点与口播对应。
- A/B/C的变化因素准确，跨实验对照不悄悄改动控制器或窗口。
- 预算候选数、训练/测试次数、协议和展示的结果属于同一轮实验。
- 无配音占位、缺音频、缺字幕、断章或仅有静态截图轮播的问题。
- 报告、配置、原始轨迹、图表与视频版本能够相互追溯。
