# v2.0 科研路线：本科研究、复试展示与论文投稿准备

日期：2026-10-25。目标来自用户明确选择：**本科科研与考研复试展示，争取投稿**。当前为研究提案，没有开展本文正式实验，没有确定创新性，也没有论文结果或录用承诺。源码仍为0.9.0.dev0。

## 一、v2.0的交付目标

形成一项可完整讲述、可复现、能交给指导老师评阅并争取投稿的研究：

1. 明确的研究问题与相关工作对照表。
2. 一个可解释的候选方法及其局限，或严谨的对比研究。
3. 公平的基线、重复实验、消融与独立冻结验证。
4. 全部原始数据、失败记录、分析和论文图表。
5. 完整论文初稿、投稿适配稿、复现说明和演示项目。

论文贡献需要由问题、方法及证据共同建立。GUI和工程平台为研究提供支撑，界面数量不作为算法创新。

## 二、建议优先研究的问题

**在相同闭环仿真预算下，如何选择更有信息的压力工况，使整定得到的同一组PID参数在未见工况中更少违反要求？**

研究对象先限定为不确定SISO系统，控制结构先固定为一种抗饱和PID，避免同时改变控制算法和实验选择策略。保留误差、输入饱和比例、控制动作变化率三类要求，并考虑对象参数、测量延迟、扰动及噪声。

工作题目暂定：

> 面向不确定SISO系统的约束感知工况采样与PID参数整定评估

标题不提前写“高效”“优越”“保证鲁棒稳定”，这些都需要对应结果或证明。最终题目随查新和实验结果调整。

因此，当前只能把“约束边界附近优先采样、兼顾全域探索、以独立验证衡量实际收益”列为**候选研究方向**。不能声称这一组合已经具有新颖性。

下一步文献差异表需要逐项核对：对象类型、约束定义、一次评价成本、候选/工况联合选择方式、噪声处理、是否存在独立未见工况、理论假设、代码及可复现程度。若与已有方法等价，应改变问题或直接复现，而不是换名称。

## 四、候选方法：先做小型可证伪原型

可探索的初始策略：

- 从覆盖声明域的初始工况开始。
- 根据已观察的各约束余量与失效分布，优先分配评价预算。
- 保留明确比例的全域探索，避免只围绕已发现区域收缩。
- 每次分配记录“选了哪个候选/工况、依据是什么、花了多少成本”。
- 所有方法完成整定后冻结参数，统一交给独立工况评估器。

需要逐一检验而不是预设成立的假设：

- 相同预算下，该策略降低未见工况的不满足比例。
- 在不牺牲约束满足的前提下，误差与动作代价至少有一项获得实际改善。
- 收益来自有效的工况选择，而非更多仿真、不同搜索范围或更宽松要求。
- 收益在不同对象任务和预算下可以重复，不依赖一个好看的示例。

不要求同时成立；如果不成立，记录适用边界，决定调整方法、转为对比研究或收缩课题。

## 五、正式实验的设计要求

### 研究单位与配对

真正的重复单位是一个任务上的**完整独立整定过程**。一条轨迹的几千个采样点、一套参数下的几百工况，以及同一对象上的重复噪声，不自动构成几千个独立算法实验。

不同方法在相同任务、可比的初始化、相同预算和同一冻结测试工况下配对比较。对象任务作为分组因素；随机化执行次序，并记录机器与计时条件。预实验用于估计运行成本和结果波动，再确定正式重复次数，不以固定“跑30次”代替设计依据。

### 基线

第一轮隔离工况选择的影响：尽量固定控制结构、候选生成器、范围、初始化与停止规则，只比较采样策略：

- 固定网格或现有固定工况协议。
- 均匀随机工况采样。
- 空间填充采样，如拉丁超立方。
- 候选的约束感知策略。

正式投稿前，应根据文献差异表补入一个适用且有竞争力的已有方法。优先评估ARBO或相关约束/鲁棒优化方法是否能在相同问题定义下复现；不能只选明显弱的对照。

再做端到端整定比较，并明确它与“只改变采样器”的实验回答不同问题。

### 预算公平

一次闭环评价定义为一个候选在一个工况/输入/噪声实现下执行一次仿真。所有初始设计、搜索、主动寻找反例、候选复查和用于选择的信息都计入开发/整定预算，不能把“额外测试”免费隐藏。

除评价次数外，记录总推进区间、仿真时长与方法额外计算时间。独立最终测试使用所有方法相同的额外预算，单独列出，不被任何方法用于选参。

若不同策略看到不同工况，训练目标值不能直接当作公平排名；主要比较统一冻结测试结果。

### 开发集与最终验证

预实验和方法开发允许迭代。正式实验前冻结问题、阈值、对象任务、预算、主选规则、统计口径及停止规则。

冻结最终测试输入与随机种子，并将其结果与调参、方法选择隔离。看到最终结果后改方法属于新一轮开发，需要新的正式验证；不能把旧测试继续称为未见。

随机抽取的域内测试、参数范围外压力测试和主动寻找的反例分别报告。反例集的失败比例不能解释为真实环境的失效概率。

### 主要指标与失败处理

建议以统一测试条件下的“不满足要求比例”作为主要结果，同时报告：

- 无法找到可行主选的完整整定重复比例。
- 误差、饱和与动作变化率各自的越限及幅度。
- 运行失败、指标无效和未完成数量。
- 达到事先性能目标所需成本、性能随预算变化曲线。
- 约束满足后的误差与动作取舍。

没有主选、运行失败或指标无效不能静默丢弃；纳入事先定义的未成功类别，另列失败原因。条件性“成功运行中的平均误差”只能作为补充。

按完整重复报告配对差异、效应量和不确定区间；同一轮里的相关工况不能当作独立算法重复。样本规模、统计方法与多重比较处理在正式实验前另行确定。

### 消融与对象覆盖

至少检验去掉约束余量信息、去掉全域探索、改变预算分配的效果。消融同样采用相同预算。

先用三类有差异的受支持任务，如一阶过程、二阶振荡和带积分/更高阶对象；具体模型、难度和数值合法域在v1.0底座验收后确定。高密度参考扫描只能作为有限网格参考，不能称为连续域真最坏值。

如果有条件争取导师支持下的小型台架。仅有仿真时完整表述仿真结论；只有缺少输入/参考/采样信息的公开输出曲线，不能直接当作闭环方法验证。

## 七、论文结构与所需证据

1. 引言：明确预算、约束与未见工况问题。
2. 相关工作：与最接近的方法逐项对照。
3. 问题定义：对象域、控制结构、要求、成本与评价分布。
4. 方法：采样/分配规则、算法步骤、复杂度与假设。
5. 实验：基线、公平预算、任务、独立重复及冻结测试。
6. 结果与消融：报告完整分布、成本曲线、失败和适用边界。
7. 结论：只总结已有证据支持的范围。

预期图表包括性能—预算曲线、未见工况要求满足情况、搜索工况分布、误差—动作取舍、消融和代表轨迹。现在不生成虚构结果图或预设提升百分比。
