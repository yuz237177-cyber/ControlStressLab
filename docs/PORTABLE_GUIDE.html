ControlStressLab v1.0 桌面版

解压完整文件夹后，双击 ControlStressLab.exe。运行环境随包提供，无需安装Python。请保留同目录的 _internal 文件夹。

先打开完整示例

  1. 进入“研究项目”，选择一阶、二阶或自定义四阶示例，点击“打开完整示例”。
  2. 双击阶段列表查看控制实验、扫描、候选搜索、冻结验证或频域分析。数据复制到个人工作区，示例原包保持不变。
  3. 在模型工作台定义自己的1～4阶对象，或在实验页选择预设对象。系数按降幂排列，控制与扰动分别定义。
  4. 在预算整定页声明要求和工况，搜索后选择主选，填写取舍依据并冻结，再运行新工况验证。
  5. 在频域页从当前实验草稿或已保存原始工况建立分析。查看Bode、内部极点、S/T和参考/扰动通道；报告保存时域和正弦核对。
  6. 回到项目页导出完整项目包 .cslproj，在其他目录导入后可查看和继续分析。

保存位置

默认工作区为当前用户的 %LOCALAPPDATA%\ControlStressLab，项目页显示实际路径。每次运行建立独立结果目录，含原始CSV、配置、模型矩阵、指标、PNG/SVG、离线HTML与文件校验值。修改草稿不会改写旧结果。

理解结果

全部示例为合成仿真，未进行硬件验证。频域对应未饱和、固定参数的数字PID线性分支；有限频段裕度不替代内部稳定性、全工况检查或鲁棒稳定性证明。LADRC仍用于原有内置对象，不支持本版通用对象/频域分析。克隆项目继承已观察输入，需要重新声明验证条件。

独立运行范围

Windows x64便携包，运行时无需外部Python或联网。已在本机隔离Python路径后运行完整桌面检查；不同机器、显卡及全新Windows环境仍需进一步复测。首次启动会建立字体缓存。退出前等待任务结束或取消保存。
