# v0.3 参数整定与冻结测试方案

本方案在本轮结果生成前写入。对象、范围、预算和选择准则预先固定；测试结果不能反馈给选择器。本实验仍是合成仿真，不是硬件数据或第三方认证。

## 对象与配对

- 一阶惯性：`tau*y'=-y+gain*u+d`，名义 gain=1、tau=1；输出尺度1、输入限幅±3。
- 二阶振荡：`m*x''+c*x'+k*x=u+d`，名义 m=1、c=0.6、k=4；输出尺度0.5 m、输入限幅±5 N。质量弹簧阻尼系统作为二阶对象的代表。
- PI（无抗饱和）、有抗饱和 PID、二自由度 PID、LADRC；控制器只获得参考和带噪声/延迟的测量。两种 PID 的微分滤波时间常数固定0.03 s。LADRC 的 b0 固定为名义值1，不随测试对象参数变化。
- 采样0.01 s，每次12 s，输入在采样间零阶保持；同一对象/场景的参考、扰动、噪声数组、限幅与采样完全配对。每次运行重置全部状态。

## 搜索预算与选择规则

每个对象、每个算法共32个候选，包括候选0的原有基线。每个候选在名义对象上运行3个训练场景：0.5 s参考阶跃；0.5—4.5 s参考斜坡；6 s扰动阶跃（幅值一阶0.2、二阶0.5）。前两者评价窗口0.5—12 s，第三者6—12 s。第三者窗口可能包含起步残差，不能称为隔离后的纯扰动效应。

候选采用固定种子9173的确定性随机搜索。正参数按对数均匀分布；beta按均匀分布。每个参数的随机数由SHA-256(种子、对象、候选序号、参数名)独立确定，PID家族共享的kp、ki候选因此配对。候选0不由随机数产生。

| 参数 | 一阶范围 | 二阶范围 |
|---|---|---|
| kp | 0.3—6 | 1—20 |
| ki | 0.1—6 | 0.2—8 |
| kd（非PI） | 0.002—0.6 | 0.2—8 |
| beta（二自由度） | 0.3—1 | 0.3—1 |
| LADRC控制带宽wc | 0.5—6 | 0.5—4 |
| LADRC观察器倍率wo/wc | 2—5 | 2—5 |

观察器带宽为min(20,wc×倍率)，对应现有Euler观察器的wo×dt≤0.2采样保护；截断意味着有效wo分布不再是无截断的对数均匀分布。基线参数沿用上轮公开配置。

选择器只接收这3次训练的指标：完整成功、全部有限，最坏训练饱和时间比例≤0.25，最坏训练输入变化率 `TV/(输入限幅×评价时长)` ≤0.6/s。可行候选中，最小化3个场景等权的NIAE均值；相同分数选序号更小者。没有可行候选则明确失败，不回退、不开始测试。

NIAE=`IAE/(输出参考尺度×评价时长)`；TV只统计评价窗口内相邻实际控制动作，终端样本不制造动作。不把误差和动作量混成任意加权总分。预算只约束候选数：不同算法的参数维数、搜索空间、先验和计算成本仍不同，不能宣称严格公平或全局最优。

## 冻结测试

选择完成后先写出`selections.json`及SHA-256，并在事件日志记录`selection_frozen`；随后才允许执行测试。每个控制器的参数在所有测试中保持不变。

| 未参与选择的测试族 | 固定条件 | 每个参数因子运行数 |
|---|---|---|
| 正弦参考 | 0.37 Hz，偏置0.65×尺度，幅值0.35×尺度，0.5 s起 | 1 |
| 扫频参考 | 0.11→0.61 Hz，其余同上 | 1 |
| 二值块扰动 | 6 s起、每0.4 s独立取±幅值，幅值一阶0.2/二阶0.5；种子101/202/303 | 3 |
| 噪声与测量延迟 | 高斯噪声标准差0.02×尺度，延迟0.07 s；种子101/202/303 | 3 |

一阶改变tau、二阶改变m，因子均为0.65、1、1.5；其余物理参数固定。控制器仍使用名义知识。正弦/扫频评价0.5—12 s，二值扰动评价6—12 s，噪声延迟评价0.5—12 s。持续变化信号使用tracking_only，不错误地要求永久恢复到常数。

每对象24个测试条件，基线和整定后分别运行：2对象×4算法×2阶段×24=384次；训练2×4×32×3=768次，总计1152次。汇总先在测试族内对参数因子/种子等权，再对4个测试族等权。各场景/因子不是独立随机样本，不报告IID置信区间或现实成功概率。

训练保存全部候选配置、逐场景指标、失败信息、轨迹指纹；基线和入选候选额外保存全部训练CSV。测试保存全部384组CSV/配置/输入/指标。失败指标为null，不作零误差；测试汇总要求整组完整，否则明确标记不可比较。图表保存PNG和SVG；源码指纹、校验和、完整性状态与ZIP一并保留。

## 验证边界

测试应覆盖配置拒绝、候选确定性和预算、无可行候选、约束筛选、测试信息隔离、冻结先于测试、配对噪声、参数失配时b0不变、输出不覆盖及导出失败。独立SciPy以记录的实际输入重放对象动力学，并用独立离散矩阵校验LADRC请求；这是数值实现对照，不是新的独立非线性闭环、真实设备验证或实验室认证。

默认完整实验以`configs/benchmark-v0.3.json`为准。命令允许减少预算、选择对象/算法、调整种子/因子及两项训练约束；必须保存实际配置。这些变更构成不同实验，不能冒用默认报告结果。搜索范围、场景和评价窗口由协议版本固定。
