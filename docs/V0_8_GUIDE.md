# v0.8约束多目标整定使用指南

当前为0.8.0.dev0本地开发版，新增六项功能已接入桌面和CLI。v0.7频域模块尚未实现，因此频域联动暂不可用；公开稳定版仍为v0.4.0。本轮没有上传GitHub。

## 启动和入口

双击根目录`Start-ControlStressLab.cmd`，或运行`python run_gui.py`。仍需要Python和`.[gui]`可选依赖，不是免Python便携包。

进入“预算整定 → 约束多目标”。“经典协议”保留原v0.3整定行为。一个新任务只处理一种对象和一种控制器结构，支持一阶/二阶对象与PI、PID_aw、TwoDOF_PID。

## 六步工作流

1. **声明要求**：从实验页建立协议，选择控制器。输入归一化RMSE、饱和比例、动作变化率上限；留空关闭该项，至少开启一项。
2. **多工况整定**：设置1～2条轴及实际取值、搜索噪声种子、候选数和搜索种子。在“参数范围与信号/验证条件”中编辑完整协议。先点击“检查计划与预算”，再开始搜索。
3. **比较候选**：默认大图展示有限可行候选中的误差/动作取舍；星号是非支配候选。点选图或候选明细表，参数与工况同步更新。“较低误差”“较平稳动作”只是定位按钮，不代表唯一最优。
4. **定位不满足项**：打开“逐工况要求 / 原始数据”，选中一行查看该工况的输出、误差、实际输入。越限、运行失败和指标无效分别显示；可以打开原始CSV。
5. **冻结后验证**：从可行候选中指定一个主选，可加一个比较候选，点击“冻结主选”。冻结完成后才能运行新工况验证；验证页不会重新挑选参数。
6. **保存选择依据**：每阶段自动生成独立目录和HTML报告。验证阶段包含搜索与冻结选择的完整副本，源目录移走后仍可查看和导出ZIP。底栏“导出完整报告”会逐文件校验。

![实际候选取舍窗口](design/v0.8-candidate-tradeoffs.png)

“候选送到实验页”使用保存的完整参数；不重新调参。实验页仍会明确拒绝其表单无法无损表达的对象/时序数值，不静默取整。控制器的完整参数保存在实验配置中。

## 指标怎样解释

- 归一化误差E=RMSE/预声明参考尺度R，评价基于合成模型真实输出。
- 动作变化率V=实际输入TV/(输入限幅×评价时长)，单位1/s；它不是能耗。
- 饱和比例按评价窗口内请求输入与实际输入的差判断，沿用现有1e−10绝对差容差。
- 可行要求所有搜索记录完整、基本指标有限，并且每项开启要求在每个工况/种子均满足。
- J1先对每个工况取最坏种子，再族内平均、族间等权；J2取全部搜索记录中最大的动作变化率。
- 无可行候选时不回退到基线，不放宽阈值，不启动验证。需要修改条件时复制草稿创建新任务。

参考尺度、评价窗口、输入限幅、对象初态和非搜索参数在任务中冻结。持续变化信号不把恢复时间空值当作0。

## 参数和工况配置

示例协议：

- `configs/tuning-first-order.json`：32个候选，24个搜索条件，搜索768次；主选/比较候选/基线验证最多90次。
- `configs/tuning-second-order.json`：二阶示例，16个候选，搜索384次，验证最多90次。
- `configs/tuning-ci.json`：3次搜索、最多3次验证的快速检查协议。

从实验页新建协议保留该页对象、基线、采样、限幅和噪声强度，参考/扰动使用新整定协议的信号模板。零噪声基准默认采用单噪声种子，防止重复确定性输入。完整协议里可以调整模板及每个阶段评价窗口。

搜索参数支持kp/ki及适用的kd/beta，声明linear/log尺度；微分滤波时间常数和抗饱和开关固定。log下界必须为正；固定零值请使用linear。基线不在搜索范围时仍保留原值，不裁剪。重复参数只计算一次，别名保存。

搜索工况是轴×族×输入种子的完整组合；验证条件是明确的点列表。修改工况轴后，验证点的字段必须同步修改。轴的值优先于模板同字段；常值扰动不能使用无作用的幅值轴。

每阶段最多6个不同信号族，噪声种子1～10个；搜索轴每轴1～21个严格递增值，验证点1～64个。总预算上限1000次闭环及200万推进区间。所有候选和完整工况先校验，再建立结果目录。

## 新工况验证与观察历史

输入重复检查使用实际对象/初态、参考/扰动/噪声数组、延迟、采样和限幅的指纹。只换名称、case_id或零噪声种子不能产生新工况。搜索和验证的相同输入会在运行前拒绝。

工作区`experiments/tuning-observations.json`记录已经启用的验证输入及对应选择记录。验证开始时先登记，即使随后取消也不把它重新视为未启用。另一份选择记录不能继续冒用相同验证条件；重跑同一冻结记录标为`reproduction_same_frozen_selection`，属于复现。

这份历史覆盖当前输出根目录，无法知道其他目录、机器或外部软件中已观察的数据；用户可在协议`observed_inputs`补充已知输入指纹。它不是第三方盲测或防篡改安全系统。

冻结选择和验证开始前都重新校验来源。开始验证前，原搜索目录仍须存在且保持完整；验证完成后，独立快照保留所有必要原始数据。P0不支持取消后的断点续算。

## 命令行与独立审计

```sh
python -m controlstresslab.tuning --config configs/tuning-first-order.json --output outputs/my-tuning/search --plots
python -m controlstresslab.tuning_validation freeze --search outputs/my-tuning/search --candidates 0 --main 0 --output outputs/my-tuning/selection
python -m controlstresslab.tuning_validation run --selection outputs/my-tuning/selection --output outputs/my-tuning/validation --plots
python scripts/check_tuning_evidence.py --suite outputs/my-tuning/validation --output outputs/my-tuning-audit.json
```

候选0只是命令语法示例，实际只能冻结搜索中可行的候选；可用`--candidates 26 12 --main 26`表示两个候选及事先主选。安装后入口为`controlstresslab-tune`和`controlstresslab-tune-validate`。

审计脚本无产品代码导入，独立核对CSV指标、PID请求/限幅/条件积分、配对、族/种子聚合、前沿和冻结记录。独立SciPy脚本可对完整轨迹重放对象动力学；不完整轨迹会明确拒绝，不能计入数值回放通过数。

完整指标与设计见[协议](V0_8_EXPERIMENT_PROTOCOL.md)，本机证据见[验收记录](V0_8_VERIFICATION.md)。有限网格与有限候选不证明连续域鲁棒稳定性或全局最优，所有案例仍是合成仿真。
