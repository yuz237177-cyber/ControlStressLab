# 首页示例

新增的 [九张完整图表](gallery/README.md) 提供PNG、SVG及离线浏览页；与本页概览使用同一套场景和控制参数。

`saturation-release.svg` 与 `preview.json` 来自当前版本实际执行的合成仿真。
JSON 保存两个场景、两种控制器的完整配置、未舍入指标及核心源码 SHA-256，不包含本机绝对路径。
本目录源码指纹按UTF-8、LF换行计算，以免Git的换行转换改变指纹；逐次完整实验manifest仍记录实际文件字节的指纹。
当前快照生成环境为Windows / Python 3.12.14；其他平台的末位浮点数可能有差异，不要求逐字节相同。

在仓库根目录重新生成：

```sh
python scripts/build_readme_preview.py
```

该命令会更新本目录的两个生成文件，无第三方运行依赖。
完整五场景报告请运行 `python run_demo.py --output outputs/my-demo`；输出目录必须不存在。

## 读图

- 普通 PID 和条件积分抗饱和 PID 采用相同增益。
- 参考在 0.5 s 从 0 跳到 140 rad/s，在 4 s 回落到 60 rad/s。
- 灰线为参考、蓝线为普通 PID、绿线为抗饱和 PID，棕色虚线为 4 s 评价事件。
- 电压限制 ±12 V；140 rad/s 超过该假设模型的可达稳态转速，是刻意构造的饱和情形。
- 输入图只展示实际发出的动作，终点没有虚构的关断动作。
- 恢复时间从评价事件计算，要求最终连续进入 ±1.2 rad/s 误差带至少 0.5 s，并仅在 12 s 观察窗口内判断。
- IAE 从 4 s 计算到 12 s，采用左端保持积分约定。

该案例适合观察积分饱和的后果，不表示抗饱和控制器在所有指标和场景都更优。
首页同时列出负载阶跃的事件后结果，避免把起步误差的改善当作负载扰动抑制的改善。
模型参数、工况和限幅均为教学假设，未经硬件验证。
