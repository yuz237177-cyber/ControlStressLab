# 数学模型与闭环时序

## 约化直流电机

忽略电枢电感，假设电气动态相对所研究的机械动态足够快：

```text
i = (u - Ke * omega) / R
J * domega/dt = Kt*i - b*omega - load
             = Kt*u/R - (b + Kt*Ke/R)*omega - load
```

| 符号 | 默认值 | 单位 | 来源 |
|---|---:|---|---|
| J | 0.01 | kg m² | 教学假设 |
| b | 0.001 | N m s/rad | 教学假设 |
| R | 1.0 | ohm | 教学假设 |
| Kt | 0.1 | N m/A | 教学假设 |
| Ke | 0.1 | V s/rad | 教学假设 |
| omega(0) | 0 | rad/s | 场景假设 |
| 电压范围 | [-12, 12] | V | 执行器假设 |

正负载抵抗正方向运动。模型允许有符号转速，不自动把转速截成零。
默认无库仑摩擦、齿隙、死区、电流限制、温升、PWM 开关过程和电枢电感。
因此不能声称高频噪声下的电流或驱动器行为真实，也不能把此模型参数当作作者现有电机的实测值。

默认无电磁转换损耗且使用一致 SI 定义，Kt 与 Ke 数值相等。字段仍独立保留；人为设置不等值时，不得继续引用理想转换功率一致性。
电气恒等式 `u*i = i²R + Ke*omega*i` 不依赖 Kt；转换功率一致要求 `Kt*i*omega = Ke*omega*i`。
电气时间常数与机械时尺度、控制/信号带宽的比较只用于适用性筛查，不能仅凭采样周期判定现实有效性。

令 D=b+Kt*Ke/R；在一个采样间隔内 u 和 load 保持不变：

```text
omega_eq = (Kt*u/R - load) / D
omega_next = omega_eq + (omega - omega_eq) * exp(-D*dt/J)
```

该更新对本约化模型及保持输入是精确的；控制器仍以有限周期采样，改变采样周期可能改变闭环表现。
“对象更新精确”不意味着控制算法或现实模型无误差。

## 时序

在 t[k]：

1. 读取真实输出 y[k] 并检测有限性，本周期缓存该读数。
2. 测量采样 m[k]=y[k]+n[k]，检测有限性。
3. 纯测量延迟 d 个周期后，控制器收到 m[k-d]；t<0 假设测量恒为初始输出，无噪声。
4. 检查输出观察边界；参考值 r[k]、延迟测量、dt 进入控制器，产生请求电压。
5. 电压限幅后得到实际输入，反馈给控制器的抗饱和逻辑。
6. 保持实际输入和负载，推进对象至 t[k+1]。

参考和负载为右连续阶跃，事件时刻必须对齐采样周期。测量噪声在采样时生成，再随测量一起延迟。
噪声是每个测量样本的标准差假设；改变 dt 并不自动保留相同的连续时间功率谱。
最终端点仅记录状态，interval_s=0，不执行额外控制步。v0.1.1 起端点输入为 null（CSV 为空），不再用0占位。
`action_taken=true` 表示输入已交给对象推进；只有推进正常返回才置 `transition_completed=true` 并记入 interval_s。
推进抛异常时不承诺对象内部状态未改变，该段只标记为未完成。
失败仍保留已读到的状态；终止时刻、最后完成推进时刻、最后观测时刻分开记录。

## PID

比例作用于误差，积分按采样累积，微分作用于测量并可一阶滤波。
第一步微分置零，避免人为的初始微分冲击。
抗饱和采用条件积分：实际限幅且当前误差会进一步推动饱和时，冻结本次积分更新。
默认 kd=0，因此演示实际上是以 PID 接口运行 PI；非零微分参数需另行验证噪声敏感性。
`derivative_filter_s=0` 表示不使用微分滤波，不表示零带宽。
