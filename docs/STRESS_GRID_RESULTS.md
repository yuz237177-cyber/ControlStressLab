每行143个采样点；这是指定网格的分类计数，不是现实失效概率，也不是控制器普遍优劣排名。

## 三个需要区分的现象

1. **延迟会显著延长恢复。** 在0.15 N m负载下，零延迟时两控制器约0.92 s恢复。
   延迟0.30 s时普通/抗饱和分别约9.13/6.78 s恢复；0.35 s采样点两者均未在本观察窗内恢复。
   这些是20秒总时长、12秒事件后观察窗口下的采样结果，格间未验证，不能据此给出精确稳定极限。
2. **目标不可达与误差带恢复不同。** 精确维持60 rad/s的负载上限为0.54 N m。
   0.55 N m时±12 V的极限稳态转速约59.09 rad/s，虽然达不到精确参考，但可以进入±1.2 rad/s带内；
   0.60 N m时极限稳态约54.55 rad/s，该误差超过误差带。未达到目标不自动意味着不稳定。
3. **较大延迟可能在负载施加前就未安定。** 两控制器分别有65条记录的事件前检查未通过，
   对应5个延迟点在13个负载幅值下重复出现，不是65个独立启动问题。
   因此同时保存同延迟零负载对照的输出增量积分，不把原始事件后跟踪误差完全归因于负载阶跃。

部分状态随负载变化并不单调，抗饱和在不同指标上也有不同表现。
本轮不拟合一条“最大允许延迟”曲线，也不把观察窗内未恢复命名为数学意义不稳定。
